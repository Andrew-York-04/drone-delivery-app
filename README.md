# NoPriorITies – Drone Delivery App

NoPriorITies is a drone delivery ordering and tracking dashboard developed for ENGR 321 at the College of Charleston. The project focuses on creating a simple, safe, and user-friendly way for customers to order small everyday items and have them delivered by drone.

## Project Goal

The goal of this project is to create a fast and precise drone delivery system while keeping safety and ease of use as the main priorities. The application is designed so that users with different levels of technical experience can easily place and track a delivery.

## Features

- Browse stores by category
- Select items and add them to a cart
- Enter a delivery address and delivery instructions
- Place a simulated drone delivery order
- Track the drone during delivery
- View drone battery, altitude, speed, and estimated time remaining
- View delivery status updates
- Confirm delivery using photo, QR code, PIN, or digital signature
- View previous deliveries

## Human Factors Design

The interface was designed around human factors principles including:

- Situation awareness
- Mental workload
- Human information processing
- Multimodal interaction
- System usability
- Error prevention

The dashboard uses simple language, clear status information, and a straightforward ordering process to reduce confusion and make drone delivery easier to understand.

## Prototype

The current version is a front-end prototype that simulates the drone delivery process. Delivery progress and drone telemetry are simulated for demonstration and usability evaluation purposes.
